# SPOT Editor

> A browser-based collaborative code editor built for Launch School peer study sessions.

- Real-time collaborative editing powered by Yjs CRDTs
- Shared, interactive REPL + code execution per study pad
- Fully serverless architecture on Cloudflare Workers, Durable Objects & Containers
